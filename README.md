# JPN LLC

A premium, bilingual single-page portfolio for JPN LLC's Japanese vehicle sourcing and export business.

## Highlights

- English and Japanese site modes
- English ↔ Japanese message translator
- Responsive luxury-vehicle showcase
- Owner profile and direct contact actions
- WhatsApp and LINE QR codes
- Front-end only React architecture
- Automated GitHub Pages deployment

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```

Managed by **AIQUE**.
